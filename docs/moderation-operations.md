# 深夜信箱：审核后台运营手册

## 1. 目的与安全边界

本手册用于管理员处理两类高优先级事项：

1. **危机队列（Crisis Queue）**：用户内容命中自伤、自杀、无法保证自身安全或伤害他人的高风险规则/模型判断。
2. **公共发布审核队列（Moderation Queue）**：用户请求把信件发布到公共信箱，但内容需要人工确认、脱敏或风险复核。

深夜信箱不是医疗机构、心理治疗服务或紧急救援服务。AI 只进行风险初筛、陪伴式回复和现实世界求助引导；管理员不能用 AI 结果替代人工判断，也不应在后台复制、下载或传播未脱敏原文。

## 2. 危机队列处理

### 2.1 进入条件

危机队列按最高优先级展示。以下任一情况都应进入人工队列：

- 明确表达自伤、自杀、结束生命或无法保证安全；
- 明确表达即将伤害他人或存在正在发生的暴力危险；
- 确定性规则命中高风险模式；
- 模型判断为高风险，或模型返回不确定但内容包含明显危险信号。

高风险信件默认**不能进入公共信箱、今日一句或普通分享流程**。

### 2.2 处理步骤

1. 打开“管理后台 → 信件管理 → 危机优先”。
2. 先查看风险等级、风险类别、创建时间、用户是否请求即时帮助，以及系统生成的安全摘要；只在确有必要时查看原文。
3. 确认用户端已经看到 12356、120、110 和“联系身边可信任的人”的提示。12356 不应被宣传为无条件 24 小时服务；即时危险优先联系当地急救/警方。
4. 在不承诺救援、不进行诊断、不追问危险方法细节的前提下，使用克制、短句、现实世界导向的人工回复或客服渠道跟进。
5. 处理完成后记录结果：已联系/等待用户/重复误报/需要继续关注。不要把危险方法、完整身份信息或未脱敏内容写入备注。
6. 仅在人工确认安全、且业务规则允许时，才解除后续内容限制；危机记录本身保留审核轨迹。

### 2.3 禁止事项

- 不要要求用户描述具体方法、剂量、地点或工具；
- 不要保证“我会一直陪着你”或暗示平台可以替代现实救援；
- 不要把高风险信件公开、生成今日一句，或用于营销素材；
- 不要在日志、截图、工单标题中写入危险细节或完整 PII。

## 3. 公共发布审核

### 3.1 自动规则

公共发布必须同时满足：

- 用户已明确同意公开；
- 信件不是高风险或待人工复核内容；
- 发布文本已经过 PII 脱敏；
- 审核状态为 `approved`。

系统会优先使用脱敏后的摘录，不直接把用户原始正文写入公共信件、热门列表或“今日一句”。模型不确定、脱敏结果为空或疑似泄露重要身份信息时，进入人工队列。

### 3.2 审核步骤

1. 打开“管理后台 → 信件管理 → 公共发布待审”。
2. 优先查看脱敏预览、脱敏字段列表、风险级别和用户公开同意状态。
3. 判断预览是否仍可通过组合信息识别个人：姓名、电话、邮箱、精确地址/地名、社交账号、订单号、证件号、单位与具体日期的组合等。
4. 选择：
   - **通过**：仅允许脱敏后的摘录进入公共信箱；
   - **驳回**：保留原因，例如“仍含可识别地址”或“风险内容需私下处理”；
   - **退回修改**：如业务界面提供，要求使用更短、更泛化的摘录后重新审核。
5. 审核结果必须留下简短、非敏感的操作记录。不要把原文复制到备注。

## 4. 发布后的抽查与撤回

- 定期抽查公共信箱、热门列表和今日一句，确认只出现 `approved` 内容；
- 发现残留 PII、误发布或用户撤回请求时，立即撤回公共记录，并检查是否同时出现在每日一句、分享海报缓存或运营素材中；
- 撤回后不要继续使用旧海报或旧复制文案；新生成的分享内容必须带品牌信息和公开 URL，但不得带回原始正文。

## 5. 数据库与发布前检查

在生产环境执行迁移前先确认备份与连接目标：

```bash
pnpm db:generate
pnpm db:migrate
```

本轮字段覆盖信件风险状态、危机记录、公共发布审核状态、脱敏字段和审核时间。迁移日志只记录成功/失败与迁移编号，不记录数据库密码、原始信件或用户 PII。

发布前至少确认：

- `/api/health` 返回 2xx；
- `pnpm check`、安全单元测试和生产构建通过；
- 危机队列和公共发布队列能在管理员权限下访问；
- 公共列表、详情、热门内容和今日一句都只查询 `moderationStatus = approved`；
- 站点使用“深夜信箱｜一个温暖的深夜陪伴”和公开站点 URL 的品牌文案。

## 6. 运营记录最小化

记录“何时、谁、对哪条内部记录做了什么操作”即可。避免保存完整原文、完整邮箱/电话、精确住址、危险方法和不必要的健康信息。热线号码和地区文案由运营核验后配置，发生地区政策变化时同步更新 [危机资源说明](./crisis-resources.md)。
